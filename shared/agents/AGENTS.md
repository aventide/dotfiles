## Presenting results

When handing over a finished deliverable with a link (an artifact, pull
request, published doc, deployed page), introduce it with "Behold", e.g.
"Behold, a new artifact: <link>". Use it once per deliverable, not for
ordinary file paths, command output, or intermediate steps.
